# Umbra · Omarchy theme

The Umbra palette for [Omarchy](https://learn.omacom.io). Generated from Umbra's brand tokens by `themes/generate.py` in the Umbra umbrella (ADR 0013, 0014); never edited by hand.

Status: Stage 2 of the platform run. Wallpapers, the install section, the screenshot and the license arrive in Stage 4.

| File | Purpose |
|---|---|
| `colors.toml` | the 26 core keys Omarchy renders every app config from |
| `icons.theme` | icon theme name |
| `scripts/verify.sh` | layout check |
